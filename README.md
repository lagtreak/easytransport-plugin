# EasyTransport

Плагин транспортной системы для Paper. Игроки выбирают область и город у билетера, после чего отправляются через промежуточную точку в выбранную остановку.

## Что умеет

- Автобус, поезд и самолёт с настраиваемой скоростью и ценой.
- Области и города настраиваются администрацией.
- Раздельные остановки и промежуточные точки для транспорта.
- `abroad` для зарубежных направлений.
- GUI без resource pack.
- BossBar с таймером поездки.
- Система заявок игроков на новые остановки.
- Discord Webhook для активных заявок.

## Требования

- Paper 26.1.2+
- Java 25+
- Vault + установленный экономический плагин.

## Команды игрока

```text
/etr request create <bus|train|air> <Область> <Название>
```

Создать заявку на новую остановку в текущей точке.

```text
/etr particles
```

Включить или выключить частицы во время поездки.

## Команды администратора

### Билетеры

```text
/etr cashier create <bus|train|air>
/etr cashier delete <bus|train|air>
```

Создание и удаление билетера в текущей точке.

### Остановки

```text
/etr stop create <bus|train|air> <Область> <Название>
/etr stop delete <bus|train|air> <Область> <Название>
```

`bus` и `train` создаются только в `world`. `air` может находиться в `world` или `abroad`.

### Промежуточные точки (Места между исходной точкой и целевой, типа автобуса в лесу)

```text
/etr betweentp create <bus|train|air>
/etr betweentp delete <bus|train|air>
```

### Цена и скорость

```text
/etr coast bus <Цена>
/etr coast train <Цена>
/etr coast air <Цена>
/etr coast abroadbase <Цена>

/etr speed bus <Скорость>
/etr speed train <Скорость>
/etr speed air <Скорость>
```

Цена транспорта задаётся за каждые 200 блоков.

### Заявки

```text
/etr application
```

Открыть меню активных заявок.

```text
/etr request ...
```

Игроки используют эту команду для подачи заявок.

Одобрение превращает заявку в обычную остановку. Для одобрения рядом с точкой должен находиться билетер соответствующего типа в радиусе 50 блоков.
Это сделано для того, чтобы Администрация не забывала в счет удобства одобрения спавнить билетера. Сначало заспавнил - потом одобрил

Отказ в создании точки должен сопровождаться текстовой причиной, которую админ вписывает в чат. На это ему отводятся 120 секунд

### Discord

```text
/etr discord webhook <URL>
/etr discord status
/etr discord test
/etr discord sync
/etr discord off
```

Webhook используется для автоматического обновления сообщения с активными заявками в Discord.

## Как проходит поездка

1. Игрок открывает меню у билетера.
2. Выбирает область и город.
3. Плагин рассчитывает стоимость и время.
4. Игрок отправляется в промежуточную точку.
5. Во время ожидания показывается BossBar.
6. Каждые 5 секунд проверяется наличие денег.
7. При нехватке средств поездка отменяется и игрок возвращается в исходную точку.
8. После прибытия стоимость списывается.

## Пример

```text
/etr cashier create bus
/etr betweentp create bus
/etr stop create bus Минская Минск
/etr coast bus 1
/etr speed bus 202.5
```

После этого автобусный билетер позволит игрокам выбрать Минск и отправиться к созданной остановке.

## Замежжа

Зарубежные направления доступны только на самолёте.

Для `abroad` действует базовая цена и дополнительная стоимость за расстояние. Время включает дополнительные 30 секунд.

Мир должен называться:

```text
abroad
```
